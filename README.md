# Harsha’s New Portfolio

A multi-page portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

Use Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm start
```

## Deploy to Vercel

1. Import this GitHub repository in Vercel.
2. Select the Next.js framework preset and keep the repository root as the root directory.
3. The included vercel.json sets npm ci as the install command and npm run build as the build command. Keep the default Next.js output directory.
4. Deploy. No environment variables are required by the current portfolio.

Pages: Home, About, Blogs, Skills, Work, and Practice. Jarvis is a local portfolio guide, not an external AI model. Coding platform statistics need network access and may fall back to dated cached data. Practice hours are illustrative sample values.

The original Sites deployment remains separate. This export uses the standard Next.js runtime for Vercel.
